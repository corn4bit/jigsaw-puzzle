Jigsaw Puzzle

A complete jigsaw puzzle game for Unity, with the full casual meta around it: a level map with chapters, coins and gems, boosters, a shop, daily rewards, chapter chests, a leaderboard, friends and a profile. Pieces are cut procedurally at runtime from any picture you give it, so adding a level is one asset, not new art, not new code.

  • Unlimited levels. Any image, any resolution, any aspect ratio, any grid from 2×2 upwards.
  • A meta that works out of the box. Every screen runs on local data and bots, and each online service (store, ads, leaderboard, friends) plugs in through one small interface.
  • No dependencies. No DOTween, no third-party packages, nothing to install first.
  • Works everywhere. Pure CPU cutting and uGUI: Built-in, URP and HDRP, desktop and mobile.
  • Full source included, with an assembly definition so it compiles separately from your game.

Requirements

Unity Unity 6 (6000.0) or newer
Render pipeline Any (Built-in / URP / HDRP)
Dependencies None
Input Unity UI event system (works with both the old and new input system)
