Quick start

Everything lives in one window: Tools ▸ Corn4Bit ▸ Jigsaw Puzzle. It opens by itself the first time the package is imported, and has four tabs.

  1. On Setup, press Open demo scene and hit Play to see the minigame running.
  2. In your own scene, press Add the puzzle to the current scene.
  3. Go to Levels and create your first level from a picture of your own.

The scene check on the Setup tab tells you if anything is missing, and its Testing shortcuts reset saved progress while you iterate.

Adding levels

This is the part the whole package is built around. A level is a single PuzzleLevel asset holding a picture and a grid.

With the wizard (recommended)

Tools ▸ Corn4Bit ▸ Jigsaw Puzzle, then the Levels tab.

  1. Drop in a picture.
  2. Pick the number of columns and rows. The wizard suggests a grid that matches the picture's proportions and previews exactly how it will be cut.
  3. Press Create level.

The wizard also fixes the texture import settings and registers the level in your library, which are the two steps that are easy to forget.

Tick Create several levels at once to drop in a whole folder of images and get one level per picture.

By hand

  1. Assets ▸ Create ▸ Corn4Bit ▸ Jigsaw Puzzle ▸ Puzzle Level
  2. Assign the picture and set columns/rows.
  3. Enable Read/Write in the picture's import settings.
  4. Add the level to your Puzzle Level Library asset.

Ordering and unlocking

Order in the library is the order shown on the level select screen. The library's Unlock Mode decides access:

  • All Unlocked: every level is playable immediately.
  • Sequential: a level unlocks when the previous one in the list is solved.

There is no cap on the number of levels.
