Quick start

Everything lives in one window: Tools ▸ Corn4Bit ▸ Jigsaw Puzzle. It opens by itself the first time the package is imported, and has four tabs.

  1. On Setup, press Open demo scene and hit Play to see the game running.
  2. In your own scene, press Add the puzzle to the current scene.
  3. Go to Levels and create your first level from a picture of your own.

The scene check on the Setup tab tells you if anything is missing, and its Testing shortcuts reset saved progress while you iterate.

Make it your own game

The demo is a finished game; turning it into yours is mostly swapping content, not writing code. A typical order, each step pointing to where it lives:

  1. Name and splash. Product name and icon in Player Settings. The splash is the LoadingScreen object in the prefab: swap the logo sprite and the title text.
  2. Pictures. Drop your pictures on the Levels tab (batch mode makes a level from each), point Puzzle Manager ▸ Level Library at your own library, then delete Demo/.
  3. Colours. Pick or make a theme on the Style tab (three are included), or repaint the sprites in Art/UI: they are plain PNGs, and the 9-slice borders keep working as long as a new picture has the same size.
  4. Fonts. The font tool on the Style tab restyles every label in one pass.
  5. The map. Chapter names, ground pictures and tints are the zones on Puzzle Level Map; the trees, houses and flowers are the Items of Puzzle Map Scenery, one sprite each; clouds, butterflies and sparkles are on Puzzle Map Ambience.
  6. Economy. Everything is an asset in Data/Meta: the currencies and the five boosters (name, icon, start amount, price), Meta Config (which of them the game uses and the level each feature opens at), Reward Table (level rewards, the daily week, chapter chests) and Avatar Set.
  7. Shop. Items, prices, bundles and offers are rows in Shop Catalog; real money goes through IPuzzlePurchaseProvider (see Shop).
  8. Words. Every text the player reads is either on a Text in the prefab or a field on the component that writes it; see Texts and wording.
  9. Sounds. Five clips on Puzzle Audio, next to the manager; the praise chime is on Puzzle Combo Praise and the coin clink on Puzzle Reward Flight.
  10. Online services. Leaderboard, friends, sharing, ads and saves each plug in through one interface; see Code map.

None of these steps needs a code change, and none of them touches the package's scripts, so later updates of the package do not undo your work.

Adding levels

This is the part the whole package is built around. A level is a single PuzzleLevel asset holding a picture and a grid.

With the wizard (recommended)

Tools ▸ Corn4Bit ▸ Jigsaw Puzzle, then the Levels tab.

  1. Drop in a picture.
  2. Pick the number of columns and rows. The wizard suggests a grid that matches the picture's proportions and previews exactly how it will be cut.
  3. Press Create level.

The wizard also fixes the texture import settings and registers the level in your library, which are the two steps that are easy to forget.

Tick Create several levels at once to drop in a whole folder of images and get one level per picture.

By hand

  1. Assets ▸ Create ▸ Corn4Bit ▸ Jigsaw Puzzle ▸ Puzzle Level
  2. Assign the picture and set columns/rows.
  3. Enable Read/Write in the picture's import settings.
  4. Add the level to your Puzzle Level Library asset.

Ordering and unlocking

Order in the library is the order shown on the level select screen. The library's Unlock Mode decides access:

  • All Unlocked: every level is playable immediately.
  • Sequential: a level unlocks when the previous one in the list is solved.

There is no cap on the number of levels.
