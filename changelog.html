[1.0.0]

First release.

Features

  • Procedural jigsaw cutting from any picture: any resolution, any aspect ratio, any grid from 2×2 upwards.
  • Levels authored as PuzzleLevel assets and ordered in a PuzzleLevelLibrary; no limit on how many a game can have.
  • Levels can also be built in memory from a texture, so a photo the player picked can be played like any other level.
  • One editor window for the whole package: setup and scene check, level authoring, restyling and support, behind four tabs.
  • Level wizard: grid suggestion, live cut preview, automatic texture import fixes, batch creation from a folder of images.
  • Play any level straight from its inspector, skipping the menu, and clear its saved progress from the same place.
  • Scene doctor that reports missing components and offers one-click fixes.
  • Works with the legacy Input Manager and the Input System package, without referencing either.
  • Per-level saving that remembers where every loose piece is lying, with a pluggable storage backend (IPuzzleSaveStore).
  • Sequential or fully unlocked level progression.
  • Win screen with Next Level and Menu buttons, or an automatic timed return.
  • One to three stars per level based on solving time, with the fastest run kept and shown on the level card. Thresholds per level, or worked out from the piece count.
  • Solved levels can be played again for a better time: reopening one deals a fresh board and leaves the record alone until it is beaten.
  • Hint button that ghosts one unplaced piece into its slot, with a counter so it can be put behind a rewarded ad.
  • Sound effects for picking up, placing and joining pieces, solving a level and tapping a button, with volume and mute on one component.
  • Re-skinning through one theme asset: elements name the role they play and the theme gives that role a colour, including elements you add yourself. Two themes included, switchable while the game runs.
  • Landscape and portrait layouts from the same prefab, with safe-area support. On a tall screen the level grid fills the space under the title and the top bar wraps to two rows when it runs out of width.
  • Rotating the device or resizing the window mid-level lays the loose pieces out again around the board, keeping joined groups together. A level saved in one orientation and continued in the other is laid out the same way.
  • Pieces and joined groups are kept on screen while dragging, and positions saved outside it are pulled back in when a level is reopened.
  • Reward hook via a UnityEvent on the completion popup and static events on PuzzleManager.
  • Self-contained animation system, so the package has no third-party dependencies.
  • Assembly definitions for runtime and editor code.

Notes

  • Requires Unity 6 (6000.0) or newer.
  • Works with the Built-in, Universal and High Definition render pipelines.
  • Bundled third-party content: the font Fredoka SemiBold, SIL Open Font License 1.1. Its licence ships alongside it in Art/Fonts/. Nothing else in the package comes from a third party.
